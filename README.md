# Random Password Generator
- A simple Python based Random Password Generator
  that creates strong and random passwords using 
  letters, numbers, and special characters.

  ## Features
  - Generates random passwords automatically
  - Allows the user to choose the password length
  - Uses uppercase and lowercase letters
  - Includes numbers and special characters
  - Easy to use and beginner friendly
  - Built entirely with Python

    ## Technologies Used
    - Python 3
    - random module
    - string module

    ## How To Run
    - Make sure Python 3 is installed.
    - Download or clone this repository
    - Open the project folder in VS Code or a terminal.
    - Run

          python
          random_password_generator.py
